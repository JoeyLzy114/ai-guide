# AI 编程学习路线：我们学 AI 编程时，到底在学什么？

我把它分成了六个阶段，从零基础入门到进阶提升，每个阶段要掌握的内容都不一样，下面一个个来讲。

![alt text](<assets/02 AI 编程学习路线/image.png>)


## 配套学习资源


## 一、AI 编程入门

这个阶段的核心就是一句话，**先把东西做出来**。
不用纠结原理，不用理解代码，做出能用的东西就是胜利。

理解 AI 编程的基本概念。比如什么是 Vibe Coding、什么是大语言模型、什么是 Token、传统编程和 AI 编程的思维区别是什么。可以阅读本教程的《Vibe Coding 简介》和《Vibe Coding 概念大全》。

![](https://pic.yupi.icu/1/image-20260520171913541.png)

AI 编程的过程：向 AI 描述需求 → 多轮对话不断优化 → 验证效果并修复问题，循环往复。


## 二、掌握主流 AI 编程工具

零代码平台的能力终究有限，想做更复杂的项目，就需要学习更专业的 AI 编程工具了。

### 工具分类

AI 编程工具大致分四类：AI 代码编辑器（如 Cursor、Codex、Trae）、AI 命令行工具（如 Claude Code）、AI 编程辅助插件（如 GitHub Copilot）、AI 零代码平台（入门阶段已经用过了）。

![](https://pic.yupi.icu/1/02_AI%E7%BC%96%E7%A8%8B%E5%B7%A5%E5%85%B7%E5%9B%9B%E5%A4%A7%E5%88%86%E7%B1%BB_compressed_v1.png)


### 三大主流工具

建议从 Cursor 开始入门，因为它有完整的可视化界面，代码编辑和审查体验是最好的。

如果 Cursor 的成本负担不起，Codex 也是很好的选择，Plus 版每月 20 美元就能用上 GPT-5.5 模型，性价比不错。可以搭配 VS Code 来查看和编辑代码。

等你熟悉了 AI 编程的工作方式，再去尝试 Claude Code 的命令行操作。


### AI 编程工具要学什么

无论你选哪个工具，要学的东西是相通的，我总结为 5 个部分。
1. 基本使用：Chat 对话、Agent 自主编程、Tab 智能补全、@ 符号引用上下文
2. 核心特性：Plan Mode 计划模式、Background Agent 后台执行、Browser Use 浏览器测试
3. 扩展增强：MCP 连接外部服务、Agent Skills 技能包
4. 使用技巧：多 Agent 并行、子 Agent 拆分任务
5. 自定义配置：规则文件定义 AI 行为规范、项目级约束


### AI 编程扩展

1. Agent 可以使用 CLI，也可以使用 MCP，也可以同时两者混用
2. MCP Server 内部可以封装 CLI 命令；也就是说：MCP 可以把 CLI 包装成标准化工具给 Agent 调用。
3. CLI 是 “底层执行手段”，MCP 是 “上层统一接口”，Agent 是 “调度大脑”。

Agent 规划任务，决定调用什么能力
Agent Skills 怎么做任务，固化工作流程、领域知识、输出规范
CLI 底层执行 shell 脚本，直接跑系统命令。工具能力不会自动告诉 AI，AI 要靠`--help`、提示词去猜命令和参数。换一个 Agent 就要重新写提示词适配腾讯云。
MCP 怎么安全、标准化地连接外部工具，统一工具调用接口

MCP 相当于给 AI 编程工具能够连接外部服务。比如通过 Figma MCP 读取设计稿生成代码，通过数据库 MCP 查询业务数据，通过联网搜索 MCP 获取最新信息。


## 三、AI 编程核心技能


### 需求分析

明确项目目标和核心功能，将大需求拆解为小任务，确定技术栈和项目架构。

一次只让 AI 完成一个小功能，做完验证没问题再继续下一个，效率反而高了很多。


### 提示词工程

一个好的提示词通常包含角色设定、背景信息、具体需求、约束条件和输出格式。

有几个万用的技巧：
1. 需求描述要具体，不要模棱两可，比如「做得好看」应该改成「背景改成蓝色渐变，按钮加圆角」
2. 遇到复杂任务时，要进行拆解
3. 给 AI 举例子，它会更容易理解
4. 学会不断追问和迭代

![alt text](<assets/02 AI 编程学习路线/{CE5B7D98-AB86-4835-90CD-FEA444526FF4}.png>)


### 上下文管理

使用项目规则文件。建议优先学习通用的 `AGENTS.md` 格式，几乎所有主流 AI 编程工具都支持。在规则文件里写入项目技术栈、编码规范、目录结构说明，AI 生成代码时就会自动遵守这些约定。

![alt text](<assets/02 AI 编程学习路线/{42348ECD-EF4A-47DD-9A98-81BA78754975}.png>)

用 @ 引用来引用文件、函数、文档作为上下文，让 AI 基于已有代码生成新代码。

还要注意上下文窗口的限制，一个对话专注于解决一个问题，解决完了就开新的对话。


### Bug 排查

向 AI 描述 Bug 时，要告诉它期望的效果和实际的效果，提供完整的错误信息，说明已尝试的解决方案。

遇到解决不了的问题，要及时回退到上一个稳定版本。如果发现 AI 卡在同一个问题上反复修不好，试试换个角度描述问题。


### Git 版本管理

用 `git diff` 查看 AI 改了什么，用 `git checkout` 回退到之前的版本。


### 项目开发流程

按照需求拆解 → 方案确认 → 逐任务实现 → 代码审查 → 重构优化的流程来推进。单次对话只做一件事，做完验证再继续。每完成一个功能，用 Git 提交一次代码，相当于打了一个存档点。

AI 生成的代码不能直接用，一定要经过审查。重点关注业务逻辑是否正确、有没有遗漏错误处理、有没有安全隐患、改动是否影响了其他功能。

还要有基本的安全意识。不要把 API Key 直接写在代码里，AI 推荐的第三方包要验证是否真实存在，用户输入要做校验。


### 项目部署上线

快速部署推荐 Vercel 平台，能够一键部署前端和全栈项目，免费额度就够用了。


### AI 编程模式

需要了解几种更成熟的 AI 编程模式，不同场景选择不同的方法，能让你做项目更稳更快。

1）Agentic Engineering 智能体工程

适合中大型项目，由 Karpathy 在提出 Vibe Coding 后进一步定义。编排 AI 智能体，设计好系统架构和约束条件，让 AI 去执行实现，你负责审查和验收质量。有规划地指挥 AI 干活。

![alt text](<assets/02 AI 编程学习路线/{59A12C51-33C0-4995-AFE0-8D531B766F44}.png>)

2）Harness Engineering 驾驭工程

适合企业级项目。

Harness 本意是马具，你可以把 AI 想象成一匹马，这个模式就是围绕它搭一整套工作环境和流程，让它跑得又快又稳。

![alt text](<assets/02 AI 编程学习路线/{C8791A97-FAE2-4E56-A418-F7B83BADE470}.png>)

3）SDD 规范驱动开发

开发方法论，强调在编码之前先创建明确的、AI 能直接理解和执行的规范文档。

传统开发流程是：想到什么写什么，边写边改，最后再补文档。这样容易导致需求不清晰、代码和文档对不上。
而 SDD 的思路正好相反：先把需求写成规范文档，并且把规范文档当作代码的唯一真相来源。

实际开发中可以灵活组合多种模式。做小工具时用 Vibe Coding 快速出活，做正经项目就切到 Agentic Engineering 的思维，项目越大越复杂就越需要 Harness 的工程化方法。


## 四、AI 编程项目实战

当你全栈项目做得比较熟练了，就可以挑战更复杂的项目了。比如在项目中接入 AI 大模型 API，做 AI 对话、AI 内容生成、AI 知识库、AI 数据分析等功能。还可以对接各种第三方服务，比如 Stripe 国际支付、对象存储、短信服务、内容审核等。

1）[AI 热点监控工具](https://www.codefather.cn/course/2026625439052627970) 是一个自动化发现并推送 AI 领域前沿热点的全网监控工具，以 Vibe Coding 为核心，实战 MCP 和 Agent Skills 扩展 AI 编程能力，掌握 AI 编程全链路工作流。


## 五、进阶提升

1）AI 编程经验技巧

这些技巧都是在大量实战中沉淀下来的，能让你的效率翻倍，包括对话技巧、代码质量保障、代码重构、性能优化、安全防护、网站美化等方面。

特别要注意，用 AI 编程时间长了后，你会遇到一些 **系统性的失败模式**。比如上下文漂移、功能倒退、架构退化、依赖膨胀等。识别这些模式能帮你提前防范，而不是等问题严重了才去补救。

2）上下文工程

这是进阶版的上下文管理。包括上下文预算设计（哪些信息常驻、哪些按需加载）、决策日志（把踩过的坑记录下来防止重复犯错）、窗口管理策略（什么时候该开新对话、什么时候该沉淀文档）等。

3）成本管理

![alt text](<assets/02 AI 编程学习路线/{B335B008-695F-4C7A-9E27-41018940531E}.png>)

4）编程技术基础

需要对常见技术栈有基本认知，知道这些技术分别是什么、能干什么，这样在和 AI 对话时能更准确地表达需求。

5）AI 大模型原理入门

搞懂大模型的基本原理，能帮你更好地驾驭 AI，知道它擅长什么、不擅长什么。

比如了解 Token 和分词、上下文窗口、温度参数，通俗理解 Transformer 和注意力机制，知道为什么会出现幻觉、为什么有上下文长度限制。

6）AI 应用开发技术栈

想做专业 AI 应用或从事 AI 应用开发岗位的话，可以学 LangChain 等 AI 开发框架、RAG 检索增强生成、AI Agent 智能体开发、MCP 服务开发。

7）产品思维和变现

这方面需要学的东西包括需求分析和产品规划、产品盈利模式设计、SEO 和 GEO 优化（让你的产品被搜索引擎和 AI 收录）、自媒体运营和推广等。


## 六、持续学习

几个月前的最佳实践现在可能已经过时了。

我的建议是，多关注 AI 编程工具的最新动态、多看别人的作品找灵感、每个月至少做一个小项目保持手感。最有效的是尝试教别人，可以写技术博客、录视频教程、在社区回答问题，更容易加深自己对知识的理解。
